# PYTHON-FLASK-NOTESAPP

PYTHON FLASK NOTESAPP is a very lightweight note taking locally hosted tool to take notes in the form of relational database. It features a local first Architecture using sqlite as the sql interpreter, python serving as the backend, HTML, CSS, and Javascript as the client side connected to the backend via Flask.

## FEATURES

1. Database is stored locally in the form of a .db file
1. completely local-first architecture, keeping your data safe and private
1. very lightweight and fast
